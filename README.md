# OriginWeave

**Browse. Act. Prove.**

OriginWeave is a Chromium-compatible, Rust-first control plane for governed AI agents on the web. It is being built around isolated sessions, typed browser actions, deterministic policy enforcement, resource governance, and verifiable provenance.

The repository is intentionally bootstrapped with a minimal default branch. Product code, architecture records, tests, and delivery automation are developed through reviewed pull requests.
